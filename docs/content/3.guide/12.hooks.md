---
title: Module hooks
---

`nuxt-typo3` exposes a set of **module-level hooks** that allow you to react to key lifecycle events of the TYPO3 Headless integration.  
You can register them inside your Nuxt app using the standard Nuxt `hook` or `nuxtApp.hook` API.

```ts
export interface ModuleHooks {
  't3:initialData': (initialData: T3InitialData) => Promise<void> | void
  't3:page': (pageData: T3Page) => Promise<void> | void
  't3:i18n': (newLocale: string, oldLocale: string) => Promise<void> | void
  't3:redirect': (redirectData: T3RedirectData) => Promise<void> | void
}
```

## t3:initialData

Triggered once when the initial TYPO3 API data is loaded.
Useful for logging, analytics, or pre-processing data before it reaches the app context.

```ts
nuxtApp.hook('t3:initialData', (data) => {
  console.log('Initial data loaded:', data)
})
```

## t3:page

Executed each time a new page is fetched from the TYPO3 API.
Runs on route changes, after the `useT3Page()` composable has resolved.

```ts
nuxtApp.hook('t3:page', (pageData) => {
  console.log('New TYPO3 page:', pageData)
})
```

## t3:i18n
Called whenever the active locale changes — for example, when switching language routes.
Receives both the new and previous locale codes.
```ts
nuxtApp.hook('t3:i18n', (newLocale, oldLocale) => {
  console.log(`Language changed from ${oldLocale} to ${newLocale}`)
})
```

## t3:redirect
Executed when TYPO3 API responds with a redirect instruction.
You can use this hook to handle or override redirect logic programmatically.
```ts
nuxtApp.hook('t3:redirect', (redirectData) => {
  console.log('Redirect detected:', redirectData)
})
```
